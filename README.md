- Негативный тест с граничным значением на не добавление книги  (41 символ) и на не добавление книги с пустой строкой

 - Позитивный тест на вывод список книг с жанром который входит в список genre
 - Негативный тест на не вывод список книг с жанром который не входит в список genre
 - Позитивный тест на возвращение словаря books_genre
 - Позитивный тест на возвращение списка книг для детей
 - Позитивный тест на добавление книги в избранное и получения списка избранных книг
 - Позитивный тест на удаление книги в избранное и получения списка избранных книг
